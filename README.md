# Notebookst
Notebookst es una aplicación web de gestión académica desarrollada en PHP + MySQL. Permite a estudiantes organizar su semestre por materias, registrar actividades (tareas, quizzes, parciales, proyectos) con fecha límite, hora, color y enlace de acceso directo, y hacer seguimiento del estado de cada entrega.
Características principales:

Dashboard con resumen de actividades por materia y progreso del semestre
Gestión completa de tareas: crear, editar, cambiar estado y eliminar
Calendario con vistas de mes, semana y día, filtrable por estado y materia
Alertas automáticas de vencimiento para entregas en las próximas 72 horas
Búsqueda global de actividades desde cualquier pantalla
Estadísticas visuales por materia con barra de progreso segmentada
Ordenamiento de tareas por fecha, nombre, tipo o estado
Tema claro/oscuro persistente con localStorage
Interfaz responsive con sidebar colapsable en móvil

Stack: PHP 8+, MySQL, PDO, HTML/CSS vanilla, JavaScript vanilla, Bootstrap Icons.
